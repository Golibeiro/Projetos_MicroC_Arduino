Neste projeto feito em sala na aula de microcontroladores, o sistema tem a função de simular 
o funcionamento de um semáforo inteligente (Funções de pedestre e veicular) e incluir o
botão para pedido de passagem, é uma versão composta pelo 'Proj_SemaInt_PedBotao', com adição
da lógica de funcionamento do Buzzer passivo, que entra em ação para representar a mudança de
estado da luz verde da passagem de pedestre, para vermelho, e simbolizar o retorno da passagem
veicular.

O código tem o tratamento dos estados para verificar a ordem das ações, em paralelo ao tempo de 
duração de cada uma desses estados. E usa do comando millis a fim de evitar o debounce desses 
pedidos feitos para o sistema. Contém a presença de várias funções treinadas durante o decorrer
das aulas de programação estruturada, e de microcontroladores.

No relatório podem ser vistos mais detalhes sobre a montagem, requisitos, objetivos e os resultados.

Esta versão foi corrigida, a fim de obter o melhor funcionamento da lógica para as funções definidas.
